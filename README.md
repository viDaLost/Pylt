# Кадр

Профессиональное мобильное веб-приложение для координации съёмочной группы. Один телефон работает как пульт, остальные — как приёмники сигнала.

## Возможности

- мгновенный зелёный/красный сигнал «в кадре» на устройствах участников;
- пульт со статусами устройств, поиском и быстрым выбором человека;
- общий чат комнаты;
- голосовая рация с режимом push-to-talk;
- звук, вибрация, системные уведомления и удержание экрана активным;
- приглашение по ссылке или шестизначному коду;
- восстановление последней сессии;
- компактный mobile-first интерфейс без повторных панелей и длинных инструкций;
- полноэкранный standalone-режим без пустых зон после запуска с главного экрана;
- отдельные двухзонные макеты пульта и приёмника для landscape-режима;
- адаптация для телефонов, планшетов и компьютеров;
- установка на главный экран как PWA;
- автоматическая публикация сайта через GitHub Pages.

## Как проходит съёмка

1. На управляющем телефоне выберите **Пульт** и создайте комнату.
2. Отправьте ссылку или покажите код участникам.
3. Участники выбирают **Приёмник**, вводят имя и подключаются.
4. Перед началом каждый участник включает звук и уведомления.
5. На пульте нажмите на нужного человека — его экран сразу станет зелёным.
6. Кнопка **Снять сигнал** возвращает все приёмники в красный режим.
7. После съёмки завершите комнату.

## Технологии

- статический HTML/CSS/JavaScript без этапа сборки;
- Firebase Anonymous Authentication;
- Firebase Realtime Database;
- WebRTC для голосовой рации;
- Service Worker и Web App Manifest для PWA;
- GitHub Actions и GitHub Pages.

## Настройка Firebase

1. Создайте проект в [Firebase Console](https://console.firebase.google.com/).
2. Добавьте Web App через значок `</>`.
3. В **Authentication → Sign-in method** включите **Anonymous**.
4. Создайте **Realtime Database**.
5. Опубликуйте правила из `firebase/database.rules.json`.
6. Вставьте конфигурацию Web App в `site/firebase-config.js`.

Формат конфигурации:

```js
export const firebaseConfig = {
  apiKey: "...",
  authDomain: "project.firebaseapp.com",
  databaseURL: "https://project.europe-west1.firebasedatabase.app",
  projectId: "project",
  storageBucket: "project.firebasestorage.app",
  messagingSenderId: "...",
  appId: "..."
};
```

Конфигурация Firebase Web App не является серверным секретом. Доступ к данным ограничивают Authentication и правила Realtime Database.

## Локальный запуск

ES-модули необходимо открывать через HTTP-сервер:

```bash
python3 -m http.server 8080 --directory site
```

После запуска откройте `http://localhost:8080`.

## Установка как приложения

Внутри стартового экрана есть кнопка **Установить** с подходящим для устройства сценарием.

- **Android / Chrome:** нажмите **Установить** или откройте меню браузера → **Установить приложение**.
- **iPhone / Safari:** нажмите **Поделиться** → **На экран «Домой»** → **Добавить**.
- **Компьютер:** используйте значок установки в адресной строке Chrome или Edge.

После установки «Кадр» открывается в отдельном окне без интерфейса браузера. Интерфейс автоматически использует всю полезную высоту, увеличивает сенсорные действия и перестраивает пульт и приёмник при повороте телефона. Для корректной иконки предусмотрены обычные, maskable и Apple Touch Icon варианты.

## Публикация через GitHub Pages

Workflow `.github/workflows/pages.yml` публикует папку `site/` после изменения ветки `main`.

1. Откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Отправьте изменения в `main`.
4. Дождитесь завершения workflow **Deploy GitHub Pages**.

## Cloud Function для очистки комнат

Функция `cleanupRooms` удаляет комнаты старше 12 часов и комнаты, остававшиеся без подключённых устройств более часа.

```bash
cd functions
npm install
npm run deploy
```

Для расписания Cloud Functions может потребоваться тариф Firebase Blaze.

## Важные ограничения

- Для синхронизации Firebase нужен интернет, даже если устройства находятся в одной Wi‑Fi-сети.
- Локальные уведомления работают, пока приложение открыто или свёрнуто; это не серверные push-уведомления.
- WebRTC зависит от разрешения микрофона, качества сети и доступности TURN/STUN.
- Перед реальной съёмкой рекомендуется проверить звук, уведомления, рацию и энергосбережение на всех устройствах.
