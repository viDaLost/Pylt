# Кадр-Сигнал

Мобильное веб-приложение для съёмочной группы:

- один телефон работает как **пульт**;
- остальные телефоны подключаются как **приёмники**;
- управляющий выбирает человека в списке;
- выбранный участник видит большой зелёный экран **«ВЫ В КАДРЕ»**;
- остальные видят красный экран **«НЕ В КАДРЕ»** и имя человека, который сейчас выбран;
- отображается состояние подключения устройств;
- комната восстанавливается после перезагрузки страницы;
- приложение можно добавить на главный экран телефона как PWA.

## Важное ограничение

Эта версия использует Firebase Realtime Database, поэтому интернет нужен даже тогда, когда все телефоны подключены к одному Wi‑Fi. Для полностью локальной работы без интернета требуется отдельный WebSocket-сервер на ноутбуке, мини-компьютере или Android-телефоне с Termux.

## Структура

```text
site/                       сайт для GitHub Pages
  index.html
  styles.css
  app.js
  firebase-config.js        сюда вставляются настройки Firebase
  manifest.webmanifest
  sw.js
  icons/
firebase/database.rules.json
.github/workflows/pages.yml  автоматическая публикация GitHub Pages
firebase.json
```

# Настройка с телефона

## 1. Создайте Firebase-проект

1. Откройте Firebase Console в браузере телефона.
2. Создайте проект.
3. Добавьте Web App через значок `</>`.
4. Скопируйте объект `firebaseConfig`.
5. Откройте **Authentication → Sign-in method** и включите **Anonymous**.
6. Откройте **Realtime Database → Create database**.
7. В разделе **Rules** вставьте содержимое файла `firebase/database.rules.json` и нажмите **Publish**.

## 2. Вставьте настройки

Откройте файл `site/firebase-config.js` и замените все значения `PASTE_...` на значения из Firebase.

Пример:

```js
export const firebaseConfig = {
  apiKey: "...",
  authDomain: "my-project.firebaseapp.com",
  databaseURL: "https://my-project.europe-west1.firebasedatabase.app",
  projectId: "my-project",
  storageBucket: "my-project.firebasestorage.app",
  messagingSenderId: "...",
  appId: "..."
};
```

Объект конфигурации Firebase не является паролем. Доступ к данным ограничивается Authentication и правилами Realtime Database.

## 3. Загрузите проект в GitHub с телефона

Самый простой способ:

1. Создайте новый публичный репозиторий на GitHub, например `camera-cue`.
2. В репозитории нажмите **Add file → Upload files**.
3. Распакуйте ZIP на телефоне и загрузите все файлы, сохранив папки.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
7. Откройте вкладку **Actions** и дождитесь выполнения `Deploy GitHub Pages`.
8. Адрес приложения появится в **Settings → Pages**.

> На iPhone удобнее сначала распаковать ZIP в приложении «Файлы». На Android — в стандартном файловом менеджере или ZArchiver.

## 4. Использование на съёмке

1. На управляющем телефоне откройте сайт и выберите **Пульт → Создать комнату**.
2. Нажмите **Поделиться ссылкой** и отправьте её участникам.
3. Каждый участник вводит имя и подключается.
4. На пульте нажмите **Выбрать** напротив нужного человека.
5. Кнопка **Никто не в кадре** переводит все приёмники в красный режим.
6. После съёмки нажмите **Завершить комнату**.

## Установка как приложение

- Android/Chrome: меню браузера → **Установить приложение** или **Добавить на главный экран**.
- iPhone/Safari: **Поделиться** → **На экран «Домой»**.

## Безопасность и эксплуатация

- Не используйте тестовые правила Firebase с публичной записью.
- Код комнаты служит приглашением; отправляйте его только участникам съёмки.
- Перед реальной съёмкой проверьте работу на всех моделях телефонов.
- Отключите энергосбережение для браузера, если телефон часто гасит экран.
- В условиях плохого интернета используйте отдельную точку доступа с устойчивым внешним соединением.

## Локальный запуск для проверки

ES-модули нельзя надёжно запускать через `file://`. Используйте любой статический сервер, например:

```bash
python3 -m http.server 8080 --directory site
```

Затем откройте `http://localhost:8080`.
